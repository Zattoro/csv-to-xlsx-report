# 📊 CSV → Excel Report

Консольная утилита, которая превращает пачку однотипных CSV (выгрузки из CRM,
складские экспорты, данные по месяцам) в один готовый Excel-отчёт:

- лист **Сводка** — сколько файлов, строк, какие колонки,
- лист **Свод по …** — группировка `по колонке X → сумма Y` (например,
  «по менеджерам → сумма продаж»),
- лист **Данные** — всё слитое содержимое: фильтр, закреплённая шапка,
  числовой формат, автоширина.

Читает CSV с любым разделителем (определяется автоматически: `,` `;` таб `|`),
с кодировкой UTF-8/BOM и числами «в европейском» формате (`1 234,56`).

## Установка

```bash
pip install openpyxl
```

## Использование

```bash
# простой вариант: папка с CSV -> report.xlsx рядом
python csv_report.py --input "D:\выгрузка"

# со сводной таблицей: "по менеджерам -> сумма продаж"
python csv_report.py --input "D:\выгрузка" --by "Менеджер" --sum "Сумма"

# рекурсивно (CSV по подпапкам), своё имя результата
python csv_report.py --input "D:\данные" -r --out "D:\отчёт_2026.xlsx"
```

## Что получает на выходе бизнес

| Лист | Содержимое |
|---|---|
| Сводка | число файлов/строк/колонок, список числовых колонок |
| Свод по \<колонке> | категории по убыванию суммы, количество строк, итоговая строка |
| Данные | все строки с фильтрами и закреплённой шапкой |

Скрипт автоматически находит числовые колонки и не портит текстовые
(номер телефона «79001234567» останется строкой, если в колонке есть не-числа).

## Стек

Python 3.10+, openpyxl (запись xlsx), стандартный `csv` (чтение). Один файл,
без зависимости от pandas — запускается на любой машине за секунды.
